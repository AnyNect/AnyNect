# AnyNect

Local-first tools for Quran study, language learning, and AI-assisted work.

## Projects

| | |
|---|---|
| **[AutoNect](https://github.com/AnyNect/AutoNect)** | An AI-shell bridge: drive a web-based AI and run the shell commands it suggests, behind a security guard. Python, FastAPI, Playwright. |
| **Raji'** | A browser Quran reader: the 604-page Dar Al-Ma'rifa mushaf in tajweed colour, per-word hotspots, live recitation tracking, and a mutashabih hifz trainer. Next.js + a local NeMo ASR service. *(private)* |
| **TutorNect** | A teacher console for guided English lessons over Google Meet. Plain HTML/JS + a tiny Python server. *(private)* |
| **Hifzly** | A streaming recitation audio pipeline: voice-activity detection, speech-to-text, and phonetic alignment. Python + FastAPI. *(private)* |
| **MuteSense** | An on-device audio classifier that mutes background music while preserving speech. C++20, ONNX Runtime, PipeWire. *(private)* |

## Focus

- Real-time Quranic recitation: live ASR, word-level tracking, mistake detection
- Local, private AI where it matters
- Plain-file tools that stay readable and run without a build step

## Stack

Python, TypeScript, React and Next.js, FastAPI, ONNX Runtime, NVIDIA NeMo, C++ and Qt, Linux
