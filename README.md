# AnyNect

```
~/anynect $ whoami
building local-first tools - Quran, language, and the machinery underneath
```

I build things that run on your own machine. No cloud where it isn't
needed, no build step where it can be avoided, no magic I can't explain.

Most of it is one problem wearing different clothes: take something
hard and human - reciting, teaching, reading - and make a computer
follow along without getting in the way.

---

## What I've built

**A Quran reader that listens.**
The 604 pages in their original tajweed colour, every word a live
element rather than a flat image. Point a mic at it and it follows the
reciter word by word - flags a wrong word, a wrong verse, a slip in a
single vowel. A local speech model does the hearing; nothing leaves the
machine.

**A trainer for the passages everyone confuses.**
The similar-sounding verses of the Qur'an, turned into drills. It
isolates the fork where two passages diverge, plays the run-up, and
knocks the moment your continuation goes wrong.

**An AI-shell bridge.**
Talk to a web-based model through a real browser, run the commands it
suggests, behind a guard that reads a command before it trusts it. The
interesting half is the security layer, not the automation.

**A teacher's console.**
A lesson, page by page, on a second screen - what to say, when to
pause, when to have the student write it down. A static server and a
folder of JSON. Nothing to build, nothing to break.

**A pipeline that hears and aligns.**
Streaming audio, voice detection, and the quiet machinery that turns
sound into a position in a text.

## How I work

- **Local first.** If it needs the network to think, it needs a reason.
- **Plain files.** A thing you can read is a thing you can fix.
- **Measure, don't guess.** Every threshold I've shipped was earned
  from a capture, not a hunch.
- **Ship, then polish.** The first version is for the problem; the
  tenth is for the person using it.
